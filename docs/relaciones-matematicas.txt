1. TERRENO
----------
Huella torres          = 544 x 3 + 462,66 + 254              = 2.348,66 m2      [C]
Indice de ocupacion    = Huella torres / Lote
                       = 2.348,66 / 15.702                   = 0,1496 -> 0,15 (15,0 %)
Area torres            = 544 x 12 x 3 + 716,66 x 12          = 28.183,92 m2     [C]
Indice de construccion = Area torres / Lote
                       = 28.183,92 / 15.702                  = 1,795 -> 1,79
IC con sotanos         = (Area torres + Area sotanos) / Lote
                       = 74.183,92 / 15.702                  = 4,72

Escala de las figuras del bloque 1:
  lado relativo de la huella = raiz(2.348,66 / 15.702) = 0,3868 del lado del lote

2. TORRES
---------
Torre 4: area construida piso = 716,66 - 254                 = 462,66 m2        [C]
Total apto. por torre         = apto. por piso x 12
  Torre 1, 2, 3 = 4 x 12 = 48
  Torre 4       = 6 x 12 = 72
  Torre 5       = 2 x 12 = 24
  Total         = 48 x 3 + 72 + 24 = 240
Area construida total torre   = area construida piso x 12
  Torre 1, 2, 3 = 544 x 12    = 6.528,00 m2
  Torre 4       = 462,66 x 12 = 5.551,92 m2
  Torre 5       = 254 x 12    = 3.048,00 m2
  Total                       = 28.183,92 m2
Area apartamentos por piso
  Torre 1, 2, 3 = 4 x 107                                         = 428,00 m2
  Torre 4       = 67,27 + 65,71 + 42,92 + 67,52 + 28,37 + 84,78   = 356,57 m2
  Torre 5       = 2 x 97                                          = 194,00 m2
Area comun por piso = area construida piso - area apartamentos piso
  Torre 1, 2, 3 = 544 - 428       = 116,00 m2
  Torre 4       = 462,66 - 356,57 = 106,09 m2
  Torre 5       = 254 - 194       =  60,00 m2
